# Linear-Regression
House price prediction using Multiple Linear Regression with Python on the USA_Housing dataset.

#  USA Housing Price Prediction

This repository contains a **Multiple Linear Regression** project that predicts house prices using the `USA_Housing` dataset. The workflow includes Exploratory Data Analysis (EDA), data cleaning, feature analysis, and model training.

###  Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-learn (LinearRegression)
* **Data Visualization:** Matplotlib, Seaborn

###  Dataset Features
The model evaluates the following independent variables to predict the house **Price**:
* Avg. Area Income
* Avg. Area House Age
* Avg. Area Number of Rooms
* Avg. Area Number of Bedrooms
* Area Population
